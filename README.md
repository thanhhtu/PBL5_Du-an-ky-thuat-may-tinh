# SMART HOME APP

## Project Description

This is a smart home system controlled via a mobile app, enabling users to manage IoT devices and track environmental data. Integrated speech recognition and AI-based processing to provide intelligent interaction, enhancing convenience and efficiency in home automation.

## Technologies Used

- **Backend**: Node.js, Express, TypeScript, TypeORM, Socket.IO
- **Frontend**: React Native, Expo
- **Database**: MySQL

## Installation Guide

### Backend

1. Navigate to the `backend` folder:
   ```powershell
   cd backend
   ```
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Start the server:
   ```powershell
   npm run start
   ```

### Frontend

1. Navigate to the `frontend` folder:
   ```powershell
   cd frontend
   ```
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Start the Expo app:
   ```powershell
   npm run start
   ```

## Main Features

- Manage and control IoT devices (lights, fans, doors, curtains)
- View device activity history
- Device status statistics
- Integrated AI for data processing and interaction
- Real-time communication via Socket.IO
- User-friendly mobile interface
